设备故障智能诊断助手 — Dify 工作流设计说明书

1. 项目背景
- 业务痛点：设备维护工程师需频繁查阅手册，响应慢。
- 目标：构建一个能自然语言问答、结合知识库的智能诊断助手。

2. 工作流概览
- 节点数量：4个（开始 → 知识检索 → 大模型  → 输出）
- 使用的模型：DeepSeek-v4-flash（LLM），text-embedding-v3（Embedding）

3. 关键节点配置说明
 3.1 知识检索节点
- 知识库名称：cnc_fault_manual
- 分段模式：父子分段（父块1500字符，子块512字符）
- 召回数量（TopK）：4
- 选择理由：父子分段可保证检索命中后能返回完整的上下文段落，避免信息碎片化。

 3.2 大模型节点
- System Prompt 核心约束：
  - 必须且只能依据参考资料回答。
  - 严禁使用预训练知识。
  - 输出格式：【故障代码】【故障现象】【可能原因】【处理建议】

4. 测试结果与优化记录
| 测试问题 | V1回答质量 | V2回答质量 |
|---------|-----------|-----------|
| 故障E101 | 缺少处理步骤 | 完整输出现象+原因+步骤 |
| 故障E205 | 格式混乱 | 格式规范，编号正确 |
